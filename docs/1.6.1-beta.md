# Hub 1.6.1 Beta · список файлов карты диска

WPF получает список страницами по 100 файлов. Python сортирует полный снимок имён и размеров из `os.scandir`, затем перед выдачей страницы проверяет файлы через `os.lstat`. Проверка пути, отпечатки файлов и их родителей, удаление, корзина и восстановление остаются в Python. Новый расчёт папки и новый список отзывают предыдущие разрешения. Для сводки карты диска по умолчанию используется Python. Экспериментальный Rust Worker по-прежнему доступен для расчёта размеров.

Медианы на Windows 11, Python 3.13.17, NTFS на C:. На каждый сценарий по 15 измерений исходного `v1.6.0.1-beta.1` и новой версии в чередующихся процессах на одних файлах. Кэш Windows прогрет, анимации отключены. Появление строк измерено до события WPF Rendering после layout. Отдельные прогоны cProfile измеряют метаданные, сортировку и вызовы для формирования разрешений. Эти числа не складываются с HTTP-замерами. [Сырые замеры и методика](../benchmarks/disk-map-files-1.6.1-beta.1-windows.json) · [Документация WPF Rendering](https://learn.microsoft.com/dotnet/desktop/wpf/graphics-multimedia/how-to-render-on-a-per-frame-interval-using-compositiontarget).

В отдельной пробе имён и размеров широкая папка заняла 718,07 мс с Python `lstat` на каждый файл, 58,89 мс с Python `scandir` и 42,52 мс с Rust. Замер Rust включает запуск процесса, ввод пути, вывод всех строк и разбор в Python. На малой папке Python `scandir` занял 0,38 мс, Rust — 20,41 мс. Расчёт отпечатков для действий и WPF в пробу Rust не входят. В поставку входит прежний Worker для сводки. [Python DirEntry.stat](https://docs.python.org/3.13/library/os.html#os.DirEntry.stat) · [Rust DirEntry::metadata](https://doc.rust-lang.org/stable/std/fs/struct.DirEntry.html#method.metadata).

Воспроизведение из корня проекта после распаковки `git archive 7ef459e` в `dist/source-v1.6.0.1-beta.1`. Для реального окна WPF требуется интерактивная Windows и доступ к loopback.

```powershell
rustc -O benchmarks/disk_map_metadata.rs -o dist/hub-disk-map-metadata-probe.exe
.venv/Scripts/python.exe -m benchmarks.disk_map_files --reference-root dist/source-v1.6.0.1-beta.1 `
  --repeats 5 --rust-probe dist/hub-disk-map-metadata-probe.exe --temp-dir dist `
  --output dist/disk-map-files-1.6.1-reproduced.json
```

Чтобы получить такой же порядок файлов, первая страница ожидает перечисления всей папки. Если файл исчез или изменился в размере до загрузки его страницы, он пропускается с предупреждением. Замеры относятся к локальному NTFS на одном ПК. Холодный кэш и отдельный SMB-сервер в этой серии не проверялись.
