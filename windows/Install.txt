Hub для Windows 11 x64

Распакуй весь архив и запусти Setup.cmd. Появятся ярлыки Hub на рабочем столе и в меню «Пуск».
Если WebView2 отсутствует, установи Microsoft Edge WebView2 Runtime с сайта Microsoft.

Для переноса базы сначала закрой старый Hub. При установке выбери «Да» и укажи папку,
где находятся старые server.py и data. Новая копия базы будет в %LOCALAPPDATA%\Hub\data.

Чтобы перенести тему и оформление, в новом Hub открой «Настройки → Настройки старой версии → Открыть в браузере».
Открывшуюся страницу используй в том же браузере и профиле, где работал старый Hub.
Настройки браузера привязаны к адресу и порту старого Hub (обычно http://127.0.0.1:8770).
Если порт отличается, открой /transfer.html на прежнем адресе старого Hub, сохрани настройки в файл и выбери «Из файла» в новом Hub.

Ctrl+K — общий поиск. Ctrl+Alt+H — открыть Hub с поиском из другого приложения.
Крестик скрывает окно в трей, пока трей включён. «Закрыть Hub» в трее завершает приложение.
