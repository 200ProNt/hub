# Hub

Локальное приложение с полезными инструментами для Windows. Слева меню, справа рабочая область.
`Ctrl+K` открывает поиск сразу по инструментам, заметкам и истории буфера.

Сейчас внутри:

- **Буфер обмена** — история всего скопированного текста: поиск, закрепление, возврат в буфер.
- **Заметки** — короткие записи: заголовок по желанию, текст, закрепление, поиск по словам.
- **Сортировка файлов** — раскладывает папку по категориям: сначала показывает демо-план,
  переносит только отмеченное, умеет отменять.
- **Дубликаты** — ищет одинаковые файлы по содержимому (не по имени), показывает группы
  и убирает лишние копии в корзину хаба с возможностью вернуть.
- **Большие файлы** — список самых тяжёлых файлов в папке по убыванию размера, с удалением
  в корзину хаба.
- **Карта диска** — круглая диаграмма: сколько места занимает каждая папка. По сектору
  можно зайти внутрь и вернуться по цепочке сверху. Внутри папки видно файлы и любой
  из них можно убрать в корзину хаба или удалить насовсем.
- **Сравнение папок** — что появилось, что пропало и что изменилось: с возможностью быстрой синхронизации и копирования файлов в один клик.
- **Сжатие картинок** — конвертация форматов (PNG, JPEG, WebP), умное сжатие, масштабирование под веб/Full HD, вставка из буфера обмена (Ctrl+V) и сохранение.
- **Медиа** — пакетная обработка видео и аудио, извлечение звуковой дорожки, сведения
  о файле, объединение, разделение, извлечение, поворот, сжатие и выгрузка текста из PDF.
- **Уборка** — старые файлы, мусорные остатки и пустые папки: сначала список, потом
  перенос отмеченного в корзину хаба.
- **Корзина** — всё, что инструменты убрали с диска: можно вернуть перенос на место
  или удалить его насовсем.
- **Мониторинг ПК** — процессор, память, список процессов с поиском и графики нагрузки.
  В настольном Hub можно выбрать дополнительные показатели диска, сети и GPU,
  изменить частоту обновлений и поставить показания на паузу.
- **Автозагрузка** — записи Run и папок Startup в настольном Hub. Есть поиск, сортировка,
  отключение с подтверждением и возврат в исходное место.
- **Приложения** — установленные приложения, доступные обновления, поиск в каталоге
  WinGet, подтверждение операций и локальная история.
- **Поиск файлов** — индекс выбранных папок, исключения, фильтры, сортировка, открытие
  расположения и копирование пути.
- **Резервные копии** — профили, расписание, версии, проверка SHA-256 и восстановление
  с просмотром возможных перезаписей.
- **Разработчику** — форматирование, минификация и проверка JSON, Regex с подсветкой и
  группами, Base64 для текста и файлов, кодирование URL и сравнение текста или кода.
- **Сценарии** — редактор шагов для сортировки, уборки, сжатия изображений и резервного
  копирования. Есть условия, предпросмотр, расписание и запуск при изменении папки.
- **Локальный ИИ** — подключение к Ollama и LM Studio, помощь с Hub, поиск по выбранным
  данным и проверяемые черновики сценариев.
- **Пакетное переименование (Renamer)** — быстрое переименование файлов по правилам (замена, нумерация, регистр, транслитерация, дата) с живым предпросмотром и отменой (Undo).
- **Хэши и безопасность (Checksum & Crypto)** — вычисление SHA-256, MD5, SHA-1, проверка подлинности файлов по контрольной сумме и генератор надёжных паролей.
- **Обмен с телефоном (QR-Drop)** — локальная передача файлов и текста по Wi-Fi между компьютером и смартфоном по QR-коду без интернета и регистрации.
- **Интеграция с треем и глобальный хоткей** — значок Hub в системном трее Windows у часов и моментальный вызов окна поиска и быстрых действий по `Ctrl+Alt+H` из любого приложения.
- **О программе** — версия, автор, лицензия MIT, история обновлений и исходный код:
  папку проекта можно открыть прямо из интерфейса.

## Приватность и безопасность

- **Локальные инструменты:** в настольной версии основные инструменты доступны только с этого компьютера. По Wi-Fi доступны маршруты QR-Drop для обмена с телефоном.
- **Защита конфиденциальных данных:** буфер обмена не сохраняет пароли из менеджеров (поддерживаются флаги `ExcludeClipboardContent` и `Clipboard Viewer Ignore`) и отфильтровывает ключи API и приватные токены.
- **Защита системных файлов:** системные папки Windows пропускаются. Корень локального диска в «Карте диска» доступен только для расчёта размеров.
- **Устойчивость к сбоям питания:** заметки и буфер обмена сохраняются с физической синхронизацией `fsync` и созданием автоматических копий `.bak`. При повреждении файла данные автоматически восстанавливаются.

## Стартовый экран и обучение

При запуске браузерной версии на секунду появляется заставка с логотипом H.
Клик или любая клавиша пропускают её. Настройка анимаций управляет показом заставки.

При первом запуске после заставки открывается короткое обучение: приветствие и четыре
шага — меню, корзина хаба, поиск и тема с приватностью. Его можно пройти целиком
(«Показать, как пользоваться») или пропустить; выбор запоминается, и второй раз оно само
не появится. Вернуться к обучению можно из вкладки «О программе» кнопкой
«Показать обучение снова».

## Запуск

**Windows 11 x64.** Запусти `Hub-Setup-Windows-x64.exe`. Установщик создаст ярлык в меню «Пуск» и предложит ярлык на рабочем столе. В архиве `Hub-Windows-x64.zip` также доступен `Setup.cmd`. Окно Hub использует WPF. Фон просвечивает, если Windows поддерживает Desktop Acrylic и включены эффекты прозрачности. Просвечивание можно выключить в настройках Hub. Если трей включён, крестик скрывает окно, а команда «Закрыть Hub» в трее завершает приложение. Без трея крестик завершает Hub.

Для переноса закрой старый Hub и выбери в установщике «Перенести данные из браузерной версии Hub». Укажи папку со старым `server.py` и `data`. Hub скопирует базу, журналы и корзину в `%LOCALAPPDATA%\Hub\data`. Тему и оформление можно перенести через «Настройки → Настройки старой версии → Открыть в браузере». Используй прежний профиль браузера. Если порт изменился, открой `/transfer.html` на старом адресе Hub, сохрани файл настроек и загрузи его кнопкой «Из файла» в новой версии.

В «Настройки → Внешний вид» доступны два оформления Hub по мотивам Liquid Glass и Material You, каждое со светлым и тёмным режимом. Просвечивание фона настраивается в Glass. В «Настройки → Обновления» можно проверить последний релиз GitHub и скачать проверенный установщик. При первом запуске каждой новой версии Hub показывает «Что нового».

В «Настройки → Эксперименты» можно включить Rust Core для карты диска. По умолчанию расчёты выполняет Python. Переключатель применяется к следующему расчёту. При сбое Rust Hub показывает предупреждение и повторяет безопасное чтение в Python. Чтобы вернуться к Python, отключи переключатель. [Устройство Rust Core и результаты замеров](docs/pre-1.6-rust.md).

В «Настройки → Обновления» выбери стабильный или бета-канал. Hub предложит последнюю версию выбранного канала. Если она старее установленной, Hub предупредит об этом перед запуском установщика.

В «Система → Автозагрузка» статус «Зарегистрировано» означает, что запись присутствует
в источнике. Windows может дополнительно отключить её для учётной записи. Издатель
берётся из метаданных файла, а статус «Проверь путь» означает, что Hub не смог
подтвердить локальный путь. Для изменения записей всех пользователей нужны права
администратора. Отключённые записи остаются на ПК и восстанавливаются из Hub.

Мониторинг читает показатели физических дисков, сети, загрузки GPU и выделенной
видеопамяти из локальных счётчиков Windows. Температуры ЦП и GPU появляются, когда
локальный WMI-провайдер LibreHardwareMonitor отдаёт показания. При недоступности
источника Hub показывает состояние «Недоступно».

Для операций с приложениями нужен WinGet из «Установщика приложений» Windows. Hub
использует каталог `winget`. Установщик может открыть собственное окно. После его
запуска Hub позволяет дождаться результата и сохраняет код завершения.

Поиск файлов хранит индекс в `%LOCALAPPDATA%/Hub/data/file-index.sqlite3`. Пока Hub
запущен, выбранные папки проверяются каждые две минуты. Можно поставить индексацию
на паузу, отменить текущий проход или перестроить индекс вручную. Содержимое
текстовых документов до 512 КиБ читается только для папок, где ты выбрал эту
настройку. Ссылки, junction, системные каталоги и данные самого Hub пропускаются.

Резервные копии создаются вручную или по интервалу, пока Hub запущен, в том числе
в трее. В выбранной папке создаётся хранилище `Hub Backups` с манифестом и блоками
файлов. Если переносишь хранилище, перенеси его целиком. Срок хранения можно задать
в профиле. Hub применяет его после успешной копии. Перед восстановлением выбери
папку и просмотри перезаписи, затем подтверди операцию.

Для видео и аудио Hub использует установленные `ffmpeg` и `ffprobe` из `PATH`.
Проверена сборка FFmpeg 9.1. Она требуется только для видео и аудио. PDF работает
через pypdf 7.1.0 (BSD-3-Clause), её лицензия включена в Windows ZIP. Hub сохраняет
результаты отдельными файлами.

Сценарии выполняются при запущенном Hub. Автоматический запуск по папке следит за
файлами верхнего уровня и обрабатывает добавленные или изменённые файлы. Для
переноса в корзину нужен ручной запуск с выбором файлов в предпросмотре. Пауза
останавливает сценарий между шагами.

«Локальный ИИ» подключается через HTTP только к `127.0.0.1` или `::1`. Для Ollama
нужна версия с выбором источника `:local`, для LM Studio — REST API v1. Экран
запрашивает список локальных моделей. Токен остаётся в памяти страницы. Черновик из
ответа модели открывается в редакторе и проходит обычный предпросмотр и подтверждение
при запуске.

### Сборка Windows

```powershell
py -m pip install -r requirements-windows.txt
powershell -NoProfile -ExecutionPolicy Bypass -File windows/build.ps1
```

Архив появится в `dist`. Для сборки отдельного установщика передай компилятор Inno Setup через `-InnoSetup 'C:\путь\к\ISCC.exe'`. Для сборки нужны Python x64 и Rust toolchain для Windows x64 с `cargo` в `PATH`. Скрипт помещает Python, worker и библиотеки в папку `HubRuntime-<версия>` рядом с `Hub.exe`. Распакуй весь ZIP перед запуском `Setup.cmd`. Установленный Hub запускается без Rust toolchain. Для запуска из исходников после установки зависимостей выполни `py desktop.py`. Экспериментальный worker для запуска из исходников можно собрать командой `cargo build --locked --release --manifest-path rust/diskmap-worker/Cargo.toml`.

### Запуск прежней версии в браузере

В нативную сборку входят только браузерная страница QR-Drop для телефона и страница переноса прежних настроек.

Двойной щелчок по `start.bat` запустит консоль и браузер.

Вручную:

```
py server.py
```

(`python server.py` — если у тебя команда называется `python`.)

Нужен только Python 3.10+ (проверено на 3.14). Внешних библиотек нет.
Для доступа с этого же компьютера используется `http://127.0.0.1:8770/`. QR-Drop использует адрес компьютера в локальной сети.

Внизу меню есть переключатель «Автозапуск». Если включить, Hub будет стартовать вместе
с Windows (запись в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, без прав
администратора) и открывать браузер сам. Запускается через `pythonw.exe`, поэтому окно
консоли не появляется. Выключить можно там же.

## Где лежат данные

В настольной версии данные лежат в `%LOCALAPPDATA%\Hub\data`, а в браузерной — в папке `data/` рядом с программой.

- `clipboard.json` — история буфера (500 последних записей, закреплённые не выкидываются);
- `notes.json` — заметки;
- `runs/` — журналы переносов файлов для кнопки «Отменить»;
- `trash/` — корзина хаба: там ждут удалённые дубликаты, файлы из карты диска, большие
  файлы и убранный уборкой мусор (включая пустые папки), пока их не вернут или не удалят
  насовсем во вкладке «Корзина».

Данные перечисленных инструментов хранятся локально. Каталог WinGet и проверка
обновлений Hub используют интернет для получения общедоступных сведений.

## Буфер обмена

Наблюдатель опрашивает номер системного буфера раз в 0,4 с и читает текст, только когда
он изменился. Понимает только текст: картинки и файлы пропускаются.

- **Фильтры по типу** — мгновенное переключение между всеми записями, ссылками, фрагментами кода и обычным текстом.
- **Подсчёт объёма** — на карточках отображается точное количество слов и символов.
- **Клик по карточке** — вернуть запись в буфер, можно сразу вставлять.
- **Закрепить** — запись поднимается наверх и не вылетает при чистке.
- **Пауза** — пока включена, новый текст не записывается (на случай паролей).
- **Очистить** — удаляет историю с компьютера, отменить нельзя.

## Заметки

Заголовок не обязателен: можно писать только текст. Заметки лежат в `data/notes.json`
и переживают перезапуск; файл пишется целиком и подменяется одним движением, поэтому
обрыв записи не ломает старую версию.

- **Экспорт** — скачивание любой отдельной заметки или всей базы заметок в форматах Markdown (`.md`) и TXT.
- **Поиск** — ищет по заголовку и тексту, регистр не важен.
- **Закрепить** — заметка уходит наверх и не тонет среди свежих.
- **Ctrl+Enter** — сохранить, **Escape** — закрыть редактор.
- Удаление заметки необратимо: она не попадает в корзину хаба.

## Сортировка файлов

Категории по умолчанию: Изображения, Видео, Музыка, Документы, Архивы, Программы, Код, Другое.
Прямо в интерфейсе кнопкой «Настроить правила» можно добавлять свои категории и привязывать любые расширения с сохранением настроек.
Скрытые файлы и подпапки не трогаются, при совпадении имён добавляется ` (1)`.
Ошибка на одном файле не мешает остальным — попадает в отчёт.

## Дубликаты

Сравнение идёт по байтам: сначала файлы делятся по размеру, потом для одинаковых
по размеру считается BLAKE2b. Имена и даты не важны — «отпуск.jpg» и «DSC_0421.jpg»
с одинаковым содержимым попадут в одну группу.

- Файлы меньше 1 КБ пропускаются: пустых и служебных мелочей слишком много.
- Служебные папки (`.venv`, `node_modules`, `site-packages`, `.git`, `build` и подобные)
  не просматриваются.
- Ничего не удаляется насовсем: выбранные копии уезжают в `data/trash/<номер>/`,
  оттуда их возвращает кнопка «Вернуть».
- В каждой группе обязательно остаётся хотя бы одна копия — сервер это проверяет.
- Кнопка «Отметить лишние» выбирает все копии, кроме самой старой; можно снимать галочки вручную.

## Большие файлы

Обход папки без ссылок, файлы сортируются по размеру. Порог по умолчанию — 20 МБ,
его можно поднять до 1 ГБ или опустить до 5 МБ. Скрытые файлы тоже видны: задача —
найти тяжёлое, а не спрятать его.

- **Удалить** — окно выбора «В корзину хаба» или «Удалить навсегда»; второй вариант
  спрашивает подтверждение ещё раз. В корзине место не освобождается, пока файл там лежит.
- Удалять можно только то, что было в последнем списке, и только если файл и его папки
  не изменились с момента показа.

## Сравнение папок

Обычный режим смотрит на размер и тип: файл есть только слева, только справа, изменился
по размеру, папка против файла. «Сравнивать содержимое» дополнительно считает BLAKE2b
и ловит правки, после которых размер остался прежним — это заметно медленнее.

- Ничего не удаляется, не переименовывается и не пишется: модуль только читает.
- Пути показываются относительно корня папок, поэтому `sub/inner/file.txt` значит одно
  и то же слева и справа.
- Сравнивать папку саму с собой нельзя — сервер откажется.

## Уборка

Три группы за один проход: старые файлы (по дате изменения), мусорные остатки
(`.tmp`, `.bak`, `.part`, `.crdownload`, `Thumbs.db` и подобное) и пустые папки.
Возраст по умолчанию — год, можно выбрать от трёх месяцев до двух лет.

- Сначала список, ничего не удаляется молча. Отмечаешь галочками или кнопкой
  «Отметить всё» в текущей группе.
- Выбранное уходит в корзину хаба одной партией — включая пустые папки, они возвращаются
  так же, как файлы.
- «Удалить навсегда» требует второго подтверждения и необратимо.
- Папка, которая наполнилась после проверки, не удалится: сервер перепроверяет пустоту.

## Корзина

Корзина хаба — не корзина Windows, а папка `data/trash/` рядом с программой.
Отдельная вкладка показывает каждый перенос целиком: откуда убрали, сколько файлов
и места, что именно лежит внутри.

- **Вернуть на место** — файлы и папки возвращаются туда, откуда их убрали. Если на месте
  уже что-то появилось, сервер не перезаписывает его и пишет, что не получилось.
- **Удалить навсегда** — только после подтверждения; вместе с файлами уходит журнал
  переноса, и вернуть их больше нельзя.
- **Очистить корзину** — то же самое для всех переносов сразу.
- Пока файл лежит в корзине, место на диске не освобождается. Удаление насовсем освобождает.
- Поштучно выбирать файлы внутри переноса нельзя: перенос возвращается целиком, иначе
  половина папки вернулась бы, а половина осталась в корзине.

## Поиск по всему

`Ctrl+K` (или `Cmd+K`) открывает окно поиска поверх страницы. Один запрос ищет
по названиям и подсказкам инструментов, по заголовкам и тексту заметок и по истории
буфера обмена.

- **Стрелки** выбирают результат, **Enter** открывает, **Escape** закрывает.
- Инструмент просто открывается. Заметка или запись буфера открывает свой инструмент
  и подставляет запрос в его поле поиска — видно, почему результат нашёлся.
- Пока запрос пустой, показываются только инструменты; заметки и буфер подключаются,
  когда есть что искать. Запрос уходит на локальный сервер (`/api/search`), наружу —
  ничего.

## Мониторинг ПК

Сервер раз в секунду снимает список процессов через WinAPI (`ctypes`), страница забирает
готовый снимок каждые 2 секунды. «Пауза» останавливает обновление, но не сам мониторинг.

- **Процессор** — доля всех ядер. Одной цифры «сейчас» не существует: процент считается
  по разнице времени процессора между двумя снимками, поэтому самый первый запрос ждёт
  около секунды, пока появятся честные числа.
- **Закрыть** — только для своих пользовательских программ. Системные процессы
  (`svchost`, `lsass`, `winlogon`, `explorer` и другие), процессы другой сессии Windows
  и сам хаб защищены. Перед закрытием сервер сверяет имя и время запуска: номер PID
  переиспользуется, и без проверки можно случайно закрыть чужой процесс.
- **Поиск и сортировка** — по имени или номеру PID; порядок по процессору, памяти или имени.
- Ничего не пишется на диск и не отправляется наружу: только чтение системы.

## Карта диска

Сервер считает размеры файлов и складывает их по папкам. На диаграмме — ближайшие
папки: самая большая начинается сверху, все файлы из корня идут одной строкой
«Файлы в этой папке», чтобы круг не превращался в кашу.

- **Сектор или строка списка** — зайти в папку. Цепочка сверху показывает, где ты,
  и по любому её звену можно вернуться.
- **Наверх** — на уровень выше, **Открыть папку** — проводник.
- **Строка «Файлы в этой папке»** — показать файлы из корня папки: от больших к маленьким,
  по 100 штук с кнопкой «Показать ещё».
- **Удалить** у файла — окно выбора: «В корзину хаба» или «Удалить навсегда». Второй вариант
  спрашивает подтверждение ещё раз, отменить его нельзя.
- Корзина хаба — не корзина Windows: файл возвращается кнопкой «Вернуть» прямо на карте, но
  место на диске он не освобождает, пока лежит в корзине. Насовсем — только через
  подтверждение, и тогда место освобождается.
- Удалять можно только то, что было в последнем открытом списке: если файл изменился,
  подменился ссылкой или папка поменялась, сервер откажется и попросит открыть список заново.
- При наведении в центре видно, сколько занимает именно эта папка и её доля.
- Символические ссылки и junction-точки пропускаются, чтобы не считать одно и то же дважды.
- Результат запоминается на 90 секунд — ходить туда-обратно быстро.
- Очень большие диски считаются долго: у карты есть предел в 250 000 файлов, дальше
  она честно пишет, что часть не посчитала.

## Движение

Переключение вкладок — не мгновенная подмена: старая панель 150 мс уезжает вверх и гаснет,
новая появляется с лёгким подъёмом. Если щёлкать быстро, побеждает последняя вкладка —
промежуточные не успевают смонтироваться. Карточки, строки списков, диалоги и переключатель
темы анимируются коротко и конечно (появление, наведение, нажатие), строки проявляются
по очереди.

Анимации включены всегда, независимо от системной настройки Windows «Эффекты анимации»: та
часто выключена по умолчанию, и сайт выглядел бы совсем без движения. Если движение мешает,
внизу слева есть переключатель «Анимации» — выбор запоминается, и тогда вкладки открываются
сразу, без переходов.
